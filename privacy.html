Chonjang-watch 개인정보처리방침

시행일: 2026-11-12

1. 사용 대상

Chonjang-watch는 촌장엔터테인먼트 내부용 도구이며, 회사가 소유한 유튜브 채널 계정 1개만 이 앱을 승인합니다. 일반 사용자를 대상으로 하지 않습니다.

2. 이용하는 정보

YouTube Data API를 통해 회사 채널에 업로드된 영상의 정보(영상 ID, 제목, 태그, 공개 상태, 예약 공개 시각, 업로드 시각, 영상 길이, 원본 파일명)를 읽습니다. 시청자 개인정보나 댓글은 수집하지 않습니다.

3. 이용 목적

방송 전 회차가 유튜브에 공개되거나 예약되는 사고를 막기 위해, 영상 정보를 방송 일정과 비교하고 내부 담당자에게 알림을 보내는 데에만 사용합니다.

4. 보관과 공유

정보는 회사의 Google 스프레드시트와 Google Cloud에만 보관되며, 제3자에게 판매하거나 제공하지 않습니다. 인증 토큰은 Google Cloud Secret Manager에 암호화되어 보관됩니다.

5. 접근 해지

채널 소유 계정에서 Google 계정 > 보안 > 서드파티 앱 액세스로 언제든 이 앱의 권한을 해지할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책 준수

Chonjang-watch의 Google API 정보 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 또한 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

Privacy Policy (English summary)

Chonjang-watch is an internal tool authorized only by Chonjang Entertainment's own YouTube channel account. It reads metadata of videos on that channel (ID, title, tags, privacy status, scheduled time, upload time, duration, original file name) via the YouTube Data API solely to compare it with the broadcast schedule and alert internal staff. Data is stored only in the company's Google Sheets and Google Cloud, is never sold or shared with third parties, and access can be revoked at any time at https://myaccount.google.com/permissions. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
